# Astra v1 検算

Python 3の標準ライブラリのみ。乱数・浮動小数点・外部パッケージを使わない。

リポジトリのルートから実行する。

```bash
python3 proposals/astra/checks/verify.py
```

標準出力が [results.json](results.json) と一致し、終了コード0、最後の `status` が `PASS` になる。

## 検査範囲

| 検査 | 全列挙する対象 |
|---|---|
| A–D | 三状態模型の証人、同一初期状態からの全4二歩経路 |
| 差の保存 | 全9状態対 × 2操作 = 18場合 |
| 履歴の更新式と状態復元式 | 全3開始状態 × 前操作2種 × 次操作2種 = 12場合 |
| 応答による状態分離 | 深度0・1、三状態核と四状態拡張 |
| 結果による操作の選別 | 終端表示0、残り一歩・二歩の全継続 |
| 追加条件Eの小状態数での不成立 | 状態数1・2・3の全更新写像、全二値観測、全開始点 = 682場合 |
| Eの四状態実現 | 四状態環の偶数時刻を含む全積状態軌道 |
| 完全観測周期の反例 | 二ビット模型の全4開始点、帰還前後の全対軌道 |

Eは有限回の時間走査では判定しない。`(状態, 時刻の偶奇)` が再訪するまでの軌道を全て調べ、その後の反復を含めて判定する。二ビット模型でも状態対が再訪するまで追い、同じ操作だけでは永久に識別されないことを確認する。

局所の恒等式は全場合を検査し、任意長への拡張は本文の帰納・直接証明に依る。682ケースの探索は最小性証明の補助であり、証明自体は本文第7節にある。

## 検査しないもの

元の3+1、自由数、Time Engine、Y軸理論のコードや定理を再検証するスクリプトではない。それらからこの模型への写像、参照元の更新、内生的選択は本稿で未構成。
