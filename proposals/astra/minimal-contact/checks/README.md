# 検算の範囲

リポジトリのルートから：

```sh
python proposals/astra/minimal-contact/checks/verify.py
```

Python標準ライブラリだけを使う。125状態と25入力対の3,125組について、局所則の出力微分恒等式を有理数で検査する。有限置換、誤差修正という比較例、参照→応答→参照更新のTaylor係数も検査する。

これは有限格子での計算チェックであり、実数全体に対する証明は本文の代数式による。ODEの数値積分、未来拘束による入力生成、参照帰還、最小性、四理論の同一性は検証していない。

`results.json` は2026-09-29に本スクリプトで生成した出力。
