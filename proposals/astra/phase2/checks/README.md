# 六状態参照ループの検算

Python 3標準ライブラリのみ。リポジトリのルートから実行する。

```bash
python3 proposals/astra/phase2/checks/verify.py
```

標準出力は [results.json](results.json) と一致し、最後が `PASS`、終了コードが0になる。

| 検査 | 完全性の範囲 |
|---|---|
| 固定則・逆写像・周期 | 全六状態 |
| E–Hの同一状態対 | 四周期を二回追跡。可逆性により差の非消失を保証 |
| 状態対の区別保存 | 全30個の異なる順序付き状態対 |
| 履歴の偶奇 | 全六局所更新と各初期状態の三周期。任意長は局所式から帰納 |
| C0の射影 | 六状態 × 二操作の全12場合 |
| R1 | 各現在状態の一意な逆軌道。窓0–3の全場合 |
| 削減 | 書き込み除去・フィードバック除去・参照変数除去 |
| 外部入力を追加したR2例 | 恒等停止と一回の再開を厳密計算。任意停止長は恒等性から従う |

R2の一般的な制限命題は、本文の有限状態対の再訪による証明を使う。短い時間走査だけで、任意長の不成立を結論しない。

外部停止／再開を含む比較例を、自律六状態系のR2成立と数えない。操作族上のDの例も、自律則が選んだ複数軌道とは数えない。
