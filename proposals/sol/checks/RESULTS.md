# Sol M0 — exhaustive check result

検算対象：`model.md` の三状態・制御環 M0。

実行するコマンド：

```bash
python3 checks/exhaustive.py
```

期待される要点：

```text
A-D checks: PASS
advance cycle: [0, 1, 2, 0]
```

長さ3の全8操作列を列挙すると、初期状態0からの終端は次の通り。

| word | trajectory | final | readout | C |
|---|---|---:|---|---|
| 000 | 0→0→0→0 | 0 | A | true |
| 001 | 0→0→0→1 | 1 | A | true |
| 010 | 0→0→1→1 | 1 | A | true |
| 011 | 0→0→1→2 | 2 | B | false |
| 100 | 0→1→1→1 | 1 | A | true |
| 101 | 0→1→1→2 | 2 | B | false |
| 110 | 0→1→2→2 | 2 | B | false |
| 111 | 0→1→2→0 | 0 | A | true |

第一稿の D では `010` と `111` を二つの許容経路として使い、`011` を排除例に使う。

両許容経路は同じ結果読み取り A を持つが、終端完全状態はそれぞれ 1 と 0。そこへ同じ advance を一回適用すると、読み取りは B と A に分かれる。

## 検算上の注意

このスクリプトは有限状態 M0 の内部整合だけを検査する。

- 既存四系統との同一性は検査しない。
- 未来因果、意識、参照元更新は検査しない。
- M0以外の全モデルに対する最小性は検査しない。
