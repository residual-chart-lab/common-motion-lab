## M0 の核

状態は `Z/3Z`、読み取りは `0,1 -> A`, `2 -> B`。各ステップの操作は stay / advance の二値制御。

同じ差を途中で別物へ置き換えず、

```text
不可視
  ↓
同じ操作で輸送
  ↓
顕在化
  ↓
観測上の帰還
  ↓
残差が次の同じ操作へ効く
```

を一つの差として追う。

結果拘束は軌道を選別する述語として別に置き、同じ結果の下に異なる経路と異なる終端完全状態が残る例を作る。

## 重要な留保

M0 は説明用の最小候補であり、四系統から導出された統一モデルではない。

状態数3については、固定読み取りと同一後続操作の条件下で A と B を同時に満たすための下限を示している。ただし、これは全ての共通モデルに対する最小性の証明ではない。

参照元自身の更新、期待、意識、未来因果、物理時間、Tusi/3+1幾何は未回収として残している。
