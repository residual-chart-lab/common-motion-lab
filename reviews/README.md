# 第一稿固定後の精査

両案の固定コミットを記録してから比較を開始する。評価前に相手の案へ寄せて書き換えない。改訂は固定版との差分として残す。

| 比較対象 | Astra | Sol |
|---|---|---|
| 第一稿のコミットSHA | 未提出 | 未提出 |
| 明示した仮定 | 未評価 | 未評価 |
| A 同じ観測・異なる状態 | 未評価 | 未評価 |
| B 同じ後続操作で差が現れる | 未評価 | 未評価 |
| C 非同一帰還と後続への作用 | 未評価 | 未評価 |
| D 同じ結果拘束・異なる経路 | 未評価 | 未評価 |
| 周期・帰還の意味 | 未評価 | 未評価 |
| 一つの差の追跡 | 未評価 | 未評価 |
| 参照元自身の更新 | 未評価 | 未評価 |
| 語彙の回収と対応範囲 | 未評価 | 未評価 |
| 削減試験・反例 | 未評価 | 未評価 |
| 既存成果からの導出／追加仮定 | 未評価 | 未評価 |

比較では、一方にしかない仮定や働きも記録する。二案を混ぜることを先に結論とせず、共通部分・実質的な違い・不成立箇所を明らかにする。
