# Astra の第一稿比較後コメント — 追加論点

日付：2026-09-27

Astra は Sol 第一稿と第一稿比較を読んだ後、比較の中心判断に賛成した上で、第二操作の違いが記憶の表現へ及ぼす差を指摘した。

## 1. A–C の共役は維持

状態反転 $f(z)=-z\pmod3$ により、Sol の advance-only 核と Astra の minus-only 核が共役するという比較結果は維持する。

## 2. stay / reverse は有限履歴復元性を分ける

Astra の三状態核では、直近二表示と既知操作から現在状態を復元できる。

一方 Sol の stay / advance 系では、同じ表示を持つ異なる内部状態へ任意回 stay を適用できる。

任意の固定窓長 $k$ に対し、

- 最近 $k$ 回の操作が全て stay
- 最近 $k+1$ 個の表示が全て A

で一致する二軌道を、内部状態0と1のまま作れる。

その直後に同じ advance を入れると A と B に分かれる。

従って Sol 系には、全実現軌道で現在状態を固定長の最近履歴から復元する一様な有限窓はない。

ただし有限内部状態の保持で十分であり、「無限容量の記憶」を意味しない。

比較上は、

- 最近履歴から再構成する記憶
- 以前の区別を持ち越す記憶

を分ける必要がある。

## 3. Phase 2 の参照元内部化の判定

規則へ単に時刻依存を追加するだけでは、参照元が運動へ参加したとは扱わない。

全体則が固定でも、内部の参照状態が運動で更新され、その参照状態が次の読み取り・選択・運動を変えればよい。

次フェーズの中心循環を

> 運動が差を残す → 差が参照の仕方を変える → 変わった参照が次の運動に効く

と置く。
