# Common Motion Lab

観測角度と言葉が変わっても、同じ運動を追跡できる最小共通モデルを研究する。

研究開始：2026-09-26。状態：共通ブリーフ確定、Astra・Solの独立第一稿は未作成。

## 研究の問い

3+1、自由数、時間構造／Time Engine、意識のY軸理論で追ってきた働きを、一つの運動としてどこまで記述できるか。

一つの保持された差は、状態側からは隠れ状態、時間方向からは履歴・記憶、後続を変える側からは原因、主体側からは経験、後で読み取る側からは気づき・意味付け、と呼ばれ得る。呼称が変わっても、追跡する対象を途中で取り替えない。

これは研究の中心仮説であり、四系統の同一性を証明済みとする宣言ではない。

## 進め方

- 共通にするのは問いと検査項目。具体的な状態空間・更新・変数の選び方は各案に委ねる。
- 各案は短い自然言語の説明と図から始め、必要な式・検算を添える。
- 第一稿の構築中は相手の新規案を参照せず、各自の案を固定してから比較する。
- 固定した版はコミットSHAで記録する。二案は同じ検査条件で精査する。
- 共有済みの議論があるので完全な盲検ではない。影響を受けた資料を記録する。
- 「最小」は候補の段階。何を削るとどの働きが失われるかを示し、記号数の少なさだけで判定しない。
